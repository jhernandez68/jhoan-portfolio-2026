# Jhoan Hernández · Portfolio 2026

Portafolio personal basado en el diseño original: fondo oscuro, acentos cian y violeta, proyectos y columna de tecnologías. Contenido profesional actualizado a septiembre de 2026.

## Ejecutar

Requiere Python 3, sin dependencias adicionales.

```bash
python -m http.server 8080
```

Abre http://localhost:8080. También puedes abrir `index.html` directamente.

## Estructura

- `index.html`: perfil, experiencia, proyectos y conocimientos.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `main.js`: año automático y carrusel accesible, con flechas, teclado, desplazamiento táctil y respeto a movimiento reducido.
- `assets/`: imágenes y CV descargable.

## Edición y publicación

Edita el contenido en `index.html` y los colores en las variables de `styles.css`. Se puede servir con cualquier hosting estático. No contiene backend ni necesita compilación. Los enlaces de contacto abren el correo y los perfiles indicados; los proyectos apuntan a sus repositorios y demo existentes.

Publicado con GitHub Pages desde la raíz de la rama `main`. El repositorio original `portfolio` permanece sin modificaciones.
